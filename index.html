    Worked examples: review meaning before performance

    Fictional examples only. This keyword matcher can match comments, quoted text and identifiers; it does not validate SQL or predict a plan. Use an authorized test database and engine-specific documentation for real analysis.

    Preserve unmatched customers

    SELECT c.id, o.id FROM demo_customers c LEFT JOIN demo_orders o ON o.customer_id = c.id AND o.created_at >= '2026-01-01';

    With the date condition in ON, LEFT JOIN retains customers without a qualifying order. Moving that condition to WHERE removes rows whose right-side value is NULL. Choose the intended result before comparing plans.

    Filter aggregate groups

    SELECT customer_id, COUNT(*) AS order_count FROM demo_orders GROUP BY customer_id HAVING COUNT(*) > 2;

    HAVING COUNT(*) > 2 keeps groups with more than two rows. COUNT(*) > 2 cannot simply be moved into WHERE at the same query level. An index, JOIN rewrite or DISTINCT removal is not automatically faster or equivalent.
